## Highlights

- **Antigravity follows current agy.** Replies and late work agy produces on its own now stream live, subagent reports no longer wait for a history reload, and model discovery no longer creates a hidden session. Keep agy current with `agy update`; this release targets the current 1.5.10 protocol.
- **Codex history restores more of the native turn.** MCP script calls join their results, images and attachments replay correctly, and command outcomes, file-change labels, model labels, durations, memory citations, searches, and Stop-hook boundaries survive history.
- **Long-running chat work is easier to inspect.** Expand long command output on demand, copy Bash commands with clear feedback, open image tool results in the existing preview, and read compact activity summaries that stay in the active popout.
- **Composer and provider edge cases are steadier.** The mention picker survives its context menu, Grok handles bare session notifications and Stop hooks, DeepSeek restores code-mode controls after rejected saves, and Pi persists stopped turns through teardown.
- **Input and settings hardening is included.** JSON-RPC accepts LF framing, prototype-named model overrides are preserved, Windows reserved device names are rejected as skill names, and patched development dependencies address the `picomatch` advisory.

Existing conversations and saved preferences load unchanged.
