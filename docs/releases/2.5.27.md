## Highlights

- **Review an agent's diff from the chat.** Hover any added or unchanged diff line and add a note; Shift+click another line to extend it into a range. Notes collect in the composer tray and travel with your next message as a fixed `File` / `Line` / `User comment` block, with the covered lines outlined while you write. File-edit cards restored from history offer the same affordance once expanded.
- **Activity lists now say what actually happened.** The summary counts every row that executed instead of dropping exploration calls, a Read card no longer repeats its own file as an extra row, and a Bash card that lists exploration keeps its command line so consecutive cards stay distinguishable.
- **Attention is one derived phase.** `needs-you`, `working`, `done`, and `rest` now come from the same facts everywhere, and the history dropdown marks rows that are waiting on you or hold an unreviewed result, tinted for errors.
- **Background turns explain themselves.** When a background turn produces no reviewable completion, the provider diagnostic log records the cause instead of leaving the reply silently missing.

Existing conversations and saved preferences load unchanged.
