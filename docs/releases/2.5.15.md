## Highlights

- **Keep a task running when you close the chat panel.** Reopening its conversation returns to the retained runtime, including pending interactions, while runtime status and Stop controls help manage active work.
- **Read longer conversations more comfortably.** Completed tool activity and task notifications fold into expandable work summaries. Scroll and focus fixes help you review earlier work and return to the composer.
- **Choose and troubleshoot your agent setup.** The model browser adds favorites and reasoning controls where supported. Claude authentication guidance explains credential conflicts, and Pi's managed launcher handling improves Windows portability.

Provider-specific features remain limited to the providers that support them. See the full change list below for individual fixes.
