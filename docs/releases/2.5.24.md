## Highlights

- **DeepSeek Harness 0.2.2 is supported.** Batched session projections, the new tool executors, full image references and headerless forks are handled while 0.2.1 keeps working. Native `apply_patch` is available with patch rendering, and cancelled startups release their locks through the stdin lease.
- **Secret answers stay private.** Completed question cards mask answers marked secret while the stored values remain available to the conversation.
- **Provider fixes land where they belong.** Codex shows structured-only MCP results, Grok dismisses questions with their requesting turn, and Pi keeps extension commands separate from attached context.
- **Composer and links behave predictably.** Same-note heading links resolve from inline-edit previews, Escape keeps a dismissed mention closed while typing, indented code examples survive prompt history, and slash-command lists are no longer swallowed as frontmatter.
- **Chat surfaces follow Obsidian.** Text scales with the note font size, the compacting indicator uses the normal thinking color, session selection follows the theme's active surface, and copy buttons keep their accessible names in sync.
- **Fork lineage is visible.** Forked conversations record their source and appear with a badge in history, with no migration required for existing sessions.

Existing conversations load unchanged, and provider features remain capability-specific.
