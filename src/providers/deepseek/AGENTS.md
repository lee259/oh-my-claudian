# DeepSeek Harness

- Preserve native Web/Desktop profiles, credentials, model defaults and MCP configuration. Launch presets are temporary overlays; never provision a Claudian user profile. Desktop launches its bundled executable as Node on its bundled Host CLI; Windows npm shims locate the package entry and must never be spawned. Verify installation discovery on macOS and Windows when changing launch code.
- `DeepSeekHost` alone owns the workspace process and transport recovery. Sessions hold leases and exclusive claims; `DeepSeekRoster` alone subscribes to global streams and resolves native subagent ancestry. An unresolved native fork retires its Host because native forks cannot be cancelled. Do not enable forking during a running turn without changing that failure behavior.
- Cold history uses projections and fixed-cut journal pages without taking native writers. Resume saved sessions through activation, never `session/create`, which can mint another session. Check the saved cwd and DSH_HOME before activation. Never remove native locks or write transcripts.
- Literal prompts are keyed by native session and apply at the next turn. Only a claimant writes its prompt, and release removes it. Code mode changes apply on the next native turn; CLI, environment and preset-plugin changes use guarded provider transitions.
- Session failures retain native work until an explicit Stop, close, or the next send rebinds. A dropped transport reconnects the existing process within a bounded budget. During recovery, observer waits and Stop deadlines pause; process retirement ends them. Unknown work remains busy until reconciliation or bounded disposal.
- Correlate requested input and steers by native request IDs. A steer is accepted only when a native step claims it; native acknowledgement is insufficient. Withdraw unclaimed inbox entries before cancelling because native cancellation retains the inbox.
- Native output is append-only. Divergence invalidates the projection and asks for history reload; native retries append without duplicating settled output. Code-mode dispatches map to ordinary tool events through the existing toolUseResult contract.
- Auxiliary sessions use the bundled ephemeral plugin only after its readiness report. Ephemeral identities and forks expire with the Host generation. The plugin decorates native persistence and keeps ephemeral children, spills and attachments in process-owned storage; never delete shared durable images. When qualifying a new Harness version, verify actual persistence, image and cancellation behavior against isolated DSH_HOME.
- Model discovery preserves explicit enabled-model order and reasoning preferences. Unavailable models remain recorded for recovery and settings but never become selector options or provider-default fallbacks. Native permissions and MCP stay provider-owned; do not expose the shared MCP selector or introduce cross-conversation coordination tools.
